# Materiais de Aulas — Inteligência Artificial

Repositório central para materiais didáticos, laboratórios, exemplos e projetos dos cursos de Inteligência Artificial.

## Organização multicurso

```text
cursos/
└── nome-do-curso/
    ├── README.md
    ├── modulos/
    ├── recursos-compartilhados/
    └── requisitos/
```

O primeiro curso estruturado neste pacote é **RAG de Ponta — Engenharia de Recuperação, Agentic RAG e GraphRAG (96h)**.

## Regras

- Nunca versionar chaves, tokens ou `.env` reais.
- Usar dados públicos, fictícios ou autorizados.
- Manter dependências específicas dentro da pasta do curso.
- Não versionar modelos, índices vetoriais ou datasets grandes.
- Preservar a hierarquia `curso → módulo → laboratório`.
