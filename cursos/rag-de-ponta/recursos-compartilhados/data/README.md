# Dados

Use somente dados públicos, fictícios ou autorizados.

- `raw/`: fontes originais, normalmente fora do Git.
- `processed/`: resultados de extração e normalização, normalmente fora do Git.
- `eval/`: pequenos conjuntos de avaliação sem dados pessoais podem ser versionados.

Registre sempre fonte, licença, data de acesso, versão e checksum.
