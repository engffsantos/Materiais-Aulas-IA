# Módulo 1 — Fundamentos e decisões arquiteturais (6h)

## Síntese

Decidir quando usar RAG e selecionar uma arquitetura compatível com os requisitos.

## Competências gerais

- Compreender o problema técnico antes de escolher a ferramenta.
- Implementar uma solução mínima reproduzível.
- Medir qualidade, custo, latência e riscos.
- Registrar decisões, falhas e evidências.

## Laboratórios obrigatórios

- [Matriz de decisão: RAG ou outra estratégia?](./laboratorios/lab-01-01-matriz-de-decisao-rag-ou-outra-estrategia/)
- [Architecture Canvas do projeto final](./laboratorios/lab-01-02-architecture-canvas-do-projeto-final/)

## Critério de conclusão do módulo

Os dois laboratórios devem estar executáveis, documentados e associados a um commit identificável.
