# Módulo 0 — Preparação, diagnóstico e baseline (4h)

## Síntese

Preparar ambientes, criar um baseline reproduzível e estabelecer evidências para comparação.

## Competências gerais

- Compreender o problema técnico antes de escolher a ferramenta.
- Implementar uma solução mínima reproduzível.
- Medir qualidade, custo, latência e riscos.
- Registrar decisões, falhas e evidências.

## Laboratórios obrigatórios

- [Preparação do ambiente e repositório reproduzível](./laboratorios/lab-00-01-preparacao-do-ambiente-e-repositorio-reproduzivel/)
- [Construção do baseline RAG mensurável](./laboratorios/lab-00-02-construcao-do-baseline-rag-mensuravel/)

## Critério de conclusão do módulo

Os dois laboratórios devem estar executáveis, documentados e associados a um commit identificável.
