# Módulo 12 — RAG multimodal, estruturado e para código (6h)

## Síntese

Roteamento e recuperação para diferentes tipos de fonte.

## Competências gerais

- Compreender o problema técnico antes de escolher a ferramenta.
- Implementar uma solução mínima reproduzível.
- Medir qualidade, custo, latência e riscos.
- Registrar decisões, falhas e evidências.

## Laboratórios obrigatórios

- [RAG multimodal para páginas, figuras e tabelas](./laboratorios/lab-12-01-rag-multimodal-para-paginas-figuras-e-tabelas/)
- [Roteamento entre documentos, dados estruturados e código](./laboratorios/lab-12-02-roteamento-entre-documentos-dados-estruturados-e-cod/)

## Critério de conclusão do módulo

Os dois laboratórios devem estar executáveis, documentados e associados a um commit identificável.
