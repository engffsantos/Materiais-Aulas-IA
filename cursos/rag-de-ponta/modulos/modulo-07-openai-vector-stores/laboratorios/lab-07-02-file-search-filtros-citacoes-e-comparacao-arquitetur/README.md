# Laboratório 7.02 — File Search, filtros, citações e comparação arquitetural

> **Obrigatório — 2h30.**

## Objetivos

- Utilizar File Search na Responses API.
- Interpretar anotações e citações.
- Comparar gerenciado e autogerido.

## Ambiente recomendado

- Google Colab para notebooks e experimentos.
- GitHub Codespaces/VS Code Web para código estruturado.
- VS Code local é opcional.
- Credenciais somente em Secrets ou variáveis de ambiente.

## Roteiro

1. Configure File Search com o store criado.
2. Registre texto, anotações, arquivos, resultados disponíveis, tokens e tempo.
3. Teste perguntas factuais, termos exatos, não respondíveis e versões.
4. Aplique filtros por categoria, versão ou tenant quando suportado.
5. Compare esforço, chunking, filtros, transparência, custo, portabilidade e operação.
