# Módulo 7 — OpenAI Vector Stores e File Search (6h)

## Síntese

Construir uma alternativa gerenciada sem instalar banco de dados.

## Competências gerais

- Compreender o problema técnico antes de escolher a ferramenta.
- Implementar uma solução mínima reproduzível.
- Medir qualidade, custo, latência e riscos.
- Registrar decisões, falhas e evidências.

## Laboratórios obrigatórios

- [Vector Store gerenciado e ciclo de vida dos arquivos](./laboratorios/lab-07-01-vector-store-gerenciado-e-ciclo-de-vida-dos-arquivos/)
- [File Search, filtros, citações e comparação arquitetural](./laboratorios/lab-07-02-file-search-filtros-citacoes-e-comparacao-arquitetur/)

## Critério de conclusão do módulo

Os dois laboratórios devem estar executáveis, documentados e associados a um commit identificável.
