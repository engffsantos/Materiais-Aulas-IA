# Como contribuir

1. Crie uma branch por curso ou melhoria.
2. Não misture materiais de cursos diferentes no mesmo diretório.
3. Cada laboratório deve conter `README.md`, pasta `starter/` e pasta `entrega/`.
4. Nunca faça commit de credenciais ou dados privados.
5. Execute o validador antes do pull request:

```bash
python cursos/rag-de-ponta/scripts/validar_estrutura.py
```
